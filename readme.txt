=== Contact Hub ===
Requires at least: 5.8
Tested up to: 6.7
Requires PHP: 7.4
Stable tag: 2.1.0
License: GPLv2 or later
Text Domain: contact-hub

A fast, accessible floating contact widget with WhatsApp, Telegram, Eitaa, Bale, Rubika, Instagram, Messenger, Viber, SMS, phone, email and custom links.

== Description ==
* No external requests: no remote CSS, fonts, icons or tracking.
* Keyboard accessible, screen-reader friendly, respects reduced motion.
* RTL ready, light / dark / auto color modes, mobile friendly.
* Business hours with online/offline status (cache-safe, evaluated in the browser).
* Prefilled messages with {page_title} and {page_url}.
* Click events pushed to dataLayer / gtag (optional).
* Shortcode: [contact_hub_buttons]
* Developer hooks: contact_hub_should_render, contact_hub_phone_digits

== Installation ==
1. Upload the contact-hub folder to /wp-content/plugins/ and activate it.
2. Go to Settings → Contact Hub, add your channels and save.
